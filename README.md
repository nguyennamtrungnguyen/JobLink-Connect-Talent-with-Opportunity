# JobLink

### Connect Talent with Opportunity

JobLink is a professional social networking platform designed to connect
job seekers and recruiters through job discovery, social posts,
real-time messaging, and online video interviews.

The project is developed as a mobile application using React Native
and Expo, with Spring Boot as the backend and MariaDB as the primary database.

---

## 📱 About The Project

JobLink combines the experience of a professional social network
with a modern job recruitment platform.

Users can:

- Create and manage professional profiles
- Share posts and interact with the community
- Search and apply for jobs
- Recruiters can create and manage job postings
- Communicate through real-time messaging
- Schedule online interviews
- Conduct interviews through video calls
- Receive notifications about important activities
